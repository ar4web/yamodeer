# Workflow Policy Decision Register

**Purpose:** resolve open business-rule choices before any routing is treated as authoritative.  
**Status:** all decisions open; no production policy is selected by this document.  
**Prototype boundary:** until signed, keep affected paths in draft/design-only mode. Do not use the browser role selector or local approval actions as real authority.

## Safe implementation order

1. Resolve **WD-01–WD-06** first; these change who may approve or whether a request advances automatically.
2. Resolve **WD-07–WD-10** before enabling quorum voting, delegated authority, returns or template publication beyond the local preview.
3. Translate each signed decision into an explicit rule record and boundary tests before wiring runtime behavior.
4. Keep all current workflow routes, delegation records, notices and audit views labelled as local prototype behavior until server-side identity, authorization, durable storage, transaction/idempotency, scheduling and notification controls are independently delivered and verified.
